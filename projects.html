Atlanta Pollen Tracker

I was frustrated that there wasn't a good daily pollen forecast for Atlanta, so I built my own forecasting model and site.

Pulls daily data, runs a statistical model, and generates forecasts with causal explanations ("why is tomorrow going to be bad?").

LimmudFest 2026 Schedule App

This Jewish learning festival only had a 28-page PDF for its program. So I built a mobile-first schedule web-app in about an hour.

Features: 188 sessions and 50 presenter bios linked, a save-for-later list, and a Focus Mode that walks you through one time slot at a time.

Family Library Tracker

An interactive visualization of our family's public library borrowing history—over 2,000 books across four library cards. Searchable, filterable, with reading trends and stats per family member.

Built in a weekend because my kids wanted to know how many books they'd read this year. Turned into a surprisingly useful tool for finding books we loved and forgot about.
