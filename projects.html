Things I've built with AI.

I use AI-assisted development ("vibe-coding") to build real tools I actually use, built from scratch with AI doing most of the coding while I handle the design and judgment calls.

Atlanta Pollen Tracker

A real-time pollen forecasting model for Atlanta—one of the worst cities for pollen in America. Pulls daily data from the Atlanta Allergy & Asthma clinic, runs a statistical model, and generates forecasts with causal explanations ("why is tomorrow going to be bad?").

Built because I wanted to know whether to keep my windows open tomorrow. The model runs daily, tracks season progress, and estimates how many bad days are left.

Family Library Tracker

An interactive visualization of our family's public library borrowing history—over 2,000 books across four library cards. Searchable, filterable, with reading trends and stats per family member.

Built in a weekend because my kids wanted to know how many books they'd read this year. Turned into a surprisingly useful tool for finding books we loved and forgot about.
